# Codex Token Inspector

在 Codex 聊天中说 **“打开本会话用量”**，就能看到这次会话用了多少输入和输出 Token，以及输入的缓存命中率。

## 安装

把本仓库的 GitHub 链接和下面这句话一起发给 Codex。如果已经在 Codex 中打开了项目目录，直接发送这句话即可：

> 请按仓库中的 [docs/installation.md](docs/installation.md) 安装 Codex Token Inspector，并验证能否打开用量面板。

## 使用

- **看其他会话**：打开面板后切到“全部会话”，搜索并选择要查看的会话。
- **看用量来自哪里**：在“按模型”和“代理明细”之间切换。默认包含子代理；只看主代理时，关闭“包含子代理”。

面板统计本机日志中已记录的用量。缓存 Token 已计入输入，推理 Token 已计入输出；缺失日志时，面板会标出统计不完整的部分。
